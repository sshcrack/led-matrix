# Default operation is automatic

Type: grilling
Status: resolved
Blocked by:

## Question

Should normal operation remain preset/weight driven, or should the product expose an automatic operating mode that hides scene eligibility, weights, transitions, and runtime-data availability unless the user opts into advanced controls?

## Answer

Automatic is the product default. The user's explicit pain point is having too many scenes and having to reason about scene membership, weights, desktop-connected variants, and preset switching. Presets and per-scene mechanics remain available as an advanced escape hatch, but future features must reduce normal setup rather than add required configuration.
